# 하드웨어 구성

## 전체 구성

시스템은 Raspberry Pi 5와 Arduino Uno R4 Minima 기반 인증 단말기를 USB 시리얼로 연결해 구성합니다.

## Raspberry Pi 5

Raspberry Pi는 사용자 정보 저장, 센서 캘리브레이션, 압력 패턴 전처리와 AI 인증 판정을 담당합니다.

- Python 3.12 기반 관리자·인증 애플리케이션 실행
- 사용자 등록 정보와 임베딩 저장
- ONNX Runtime을 이용한 AI 모델 추론
- Arduino와 USB 시리얼 통신

## Arduino Uno R4 Minima

Arduino는 현장 인증 단말기의 입력·출력과 잠금장치 제어를 담당합니다.

- 키패드 입력 처리
- FSR402 압력 데이터 수집
- OLED·LED 출력
- 솔레노이드 잠금장치 제어
- Raspberry Pi와 시리얼 통신

## 입력 장치

### FSR402

사용자가 누르는 압력의 크기와 시간 변화를 연속적으로 수집합니다. 인증에는 단일 압력값이 아니라 입력 시작부터 종료까지의 전체 압력 변화 흐름을 사용합니다.

### TLV9002

압력센서 신호를 Arduino가 안정적으로 읽을 수 있도록 증폭 회로에 사용합니다.

### NT-207NN-WB 키패드

User ID와 단말기 명령을 입력하는 데 사용합니다. 키패드 입력은 외부 키패드 라이브러리에 의존하지 않고 펌웨어에서 행·열을 직접 스캔합니다.

## 출력 및 제어 장치

### 1.3인치 OLED

- User ID 입력 안내
- 압력 패턴 입력 안내
- 등록·인증 결과
- 오류 및 재시도 안내

### LED

잠금 상태와 압력 입력 상태를 사용자에게 표시합니다.

### MOSFET / 다이오드 / Solenoid Lock

Arduino의 제어 신호로 외부 전원을 사용하는 솔레노이드를 구동합니다. 다이오드는 솔레노이드에서 발생하는 역기전력으로부터 회로를 보호합니다.

## 압력 데이터 수집 주기

Arduino는 압력센서 값을 약 5ms 간격, 즉 200Hz 주기로 읽어 Raspberry Pi에 전달합니다.

## 설치 시 주의사항

- 솔레노이드는 Arduino의 5V 출력에 직접 연결하지 않고 별도 전원과 구동 회로를 사용합니다.
- OLED I²C 배선은 가능한 한 짧게 구성합니다.
- 센서나 증폭 회로를 교체하거나 기구 고정 상태가 변한 경우 Raspberry Pi 관리자 메뉴에서 센서 캘리브레이션을 다시 수행합니다.
- 부팅 중 의도치 않은 잠금 해제를 막기 위해 펌웨어 초기화 시 잠금 상태를 우선 설정합니다.
