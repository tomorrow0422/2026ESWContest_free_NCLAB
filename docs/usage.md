# 시스템 사용 방법

## 일반 사용자

일반 사용자는 Arduino 기반 인증 단말기만 조작합니다. Raspberry Pi 관리자 화면을 사용할 필요가 없습니다.

### 인증

1. 대기 상태의 단말기에서 아무 키나 눌러 화면을 활성화합니다.
2. 숫자 키로 자신의 User ID를 입력합니다.
3. `*` 키로 User ID를 확정합니다.
4. 등록된 사용자이면 압력 패턴 입력 화면으로 전환됩니다.
5. FSR402 센서에 자신이 등록한 연속 압력 패턴을 입력합니다.
6. `*` 키로 입력을 완료합니다.
7. 인증 결과를 기다립니다.
8. 성공하면 잠금장치가 해제됩니다. 실패하면 화면 안내에 따라 다시 입력합니다.

### 입력 수정·취소

- User ID 입력 중 짧은 `#`: 마지막 숫자 삭제
- User ID 입력 중 긴 `#`: 입력 전체 삭제
- 압력 입력 중 짧은 `#`: 현재 패턴 다시 입력
- 등록·인증 중 긴 `#`: 현재 작업 취소
- 인증 성공 상태의 `#`: 잠금장치 즉시 잠금

## 관리자

관리자는 Raspberry Pi 5에서 `nclab-auth`를 실행합니다.

### 시스템 시작

```bash
cd raspberrypi
source .venv/bin/activate
nclab-auth
```

관리자 메뉴에서 시리얼 연결을 설정하고 Arduino 장치를 선택합니다. 펌웨어 기본 보드레이트는 `115200`입니다.

### 센서 캘리브레이션

최초 설치 시 압력이 가해지지 않은 센서 기준값을 수집합니다. 캘리브레이션 결과는 이후 사용자 등록과 인증의 전처리에 동일하게 적용됩니다.

센서, 증폭 회로, 배선 또는 센서 고정 상태가 달라진 경우 다시 캘리브레이션하는 것을 권장합니다.

### 사용자 등록

1. `사용자 등록`을 선택합니다.
2. 숫자 1~10자리 User ID와 사용자 이름을 입력합니다.
3. Arduino 단말기에서 첫 번째 압력 패턴을 입력합니다.
4. 두 번째 압력 패턴을 입력합니다.
5. 두 패턴의 특징 벡터 유사도가 기준을 만족하면 등록이 완료됩니다.

등록 시 두 패턴의 임베딩을 평균하고 정규화해 기준 임베딩으로 저장합니다.

### 등록 사용자 관리

관리자 메뉴에서 다음 작업을 할 수 있습니다.

- 등록 사용자 목록 조회
- 기존 사용자 압력 패턴 재등록
- User ID와 이름 수정
- 사용자 삭제

모델 버전이 변경되어 기존 등록 임베딩을 사용할 수 없는 경우 사용자 목록에 재등록 필요 상태가 표시됩니다.

### 인증 실패 잠금

연속적인 인증 실패는 사용자별로 기록됩니다. 설정된 최대 실패 횟수에 도달하면 일정 시간 추가 인증을 제한해 반복 시도를 줄입니다.

## AI 모델

공개 저장소에는 AI 모델 가중치가 없습니다. 대회 시연 Raspberry Pi에는 모델과 설정 파일이 별도로 설치되어 있어야 합니다.

기본 경로:

```text
/opt/nclab-alt-auth/model/signature_embedding_v1.onnx
/opt/nclab-alt-auth/model/model_config.json
```

다른 경로를 사용할 경우 `NCLAB_MODEL_PATH`, `NCLAB_MODEL_CONFIG_PATH` 환경변수를 사용합니다.
