# 시스템 구성 및 동작 흐름

## 시스템 구성

본 시스템은 일반 사용자가 조작하는 **Arduino 인증 단말기**와 관리자가 운영하는 **Raspberry Pi 관리자·인증 애플리케이션**으로 구성됩니다.

### Arduino 인증 단말기

- User ID 입력
- FSR402 연속 압력 패턴 수집
- OLED·LED 상태 표시
- Raspberry Pi와 시리얼 통신
- 인증 결과에 따른 솔레노이드 잠금장치 제어

### Raspberry Pi 5

- 관리자 메뉴 제공
- 사용자 등록·조회·수정·삭제
- 센서 캘리브레이션 저장
- 압력 패턴 전처리
- AI 모델을 이용한 임베딩 벡터 추출
- 등록 임베딩과 신규 입력 비교
- 인증 결과를 Arduino에 전달

## 사용자 등록 흐름

1. 관리자가 Raspberry Pi 관리자 메뉴에서 사용자 등록을 시작합니다.
2. User ID와 이름을 입력합니다.
3. Raspberry Pi가 Arduino에 압력 패턴 수집을 요청합니다.
4. 사용자가 첫 번째 압력 패턴을 입력합니다.
5. Raspberry Pi가 입력을 전처리하고 임베딩을 추출합니다.
6. 두 번째 압력 패턴을 같은 방식으로 수집합니다.
7. 두 입력의 코사인 유사도가 등록 기준을 만족하는지 확인합니다.
8. 조건을 만족하면 두 임베딩의 평균을 정규화해 사용자 기준 임베딩으로 저장합니다.

두 번의 등록 패턴을 사용하는 이유는 한 번의 우연한 입력에 과도하게 의존하지 않고 사용자의 반복 가능한 특징을 기준 패턴에 반영하기 위해서입니다.

## 사용자 인증 흐름

1. 일반 사용자가 Arduino 단말기에 User ID를 입력합니다.
2. Raspberry Pi가 현재 모델 버전으로 등록된 사용자인지 확인합니다.
3. 등록된 사용자인 경우 Arduino가 압력 패턴을 수집합니다.
4. Raspberry Pi는 저장된 센서 캘리브레이션을 반영해 입력을 전처리합니다.
5. 연속 압력 데이터를 AI 모델 입력 형태로 변환합니다.
6. Siamese Network에서 학습된 특징 추출 인코더를 통해 임베딩 벡터를 생성합니다.
7. 등록 임베딩과 신규 임베딩의 코사인 유사도를 계산합니다.
8. 유사도가 설정된 인증 임계값 이상이면 승인, 미만이면 거부합니다.
9. 결과를 Arduino에 전달합니다.
10. 인증 성공 시 Arduino가 잠금장치를 해제합니다.

## AI 인증 방식

연속 압력 패턴은 같은 사용자가 입력해도 최대 압력, 지속시간과 변화 흐름이 조금씩 달라집니다. 따라서 원시 센서값을 고정 규칙으로 직접 비교하지 않고, 압력 패턴의 특징을 임베딩 공간으로 변환해 비교합니다.

모델은 사용자 자체를 분류하는 것이 아니라 같은 사용자의 패턴은 가깝게, 다른 사용자의 패턴은 멀어지도록 학습합니다. 이 구조를 통해 학습 완료 후 신규 사용자를 추가할 때 모델을 다시 학습하지 않고 기준 임베딩만 등록할 수 있습니다.

## 학습과 실행의 분리

모델 학습과 성능 평가는 별도의 고성능 컴퓨터에서 오프라인으로 수행했습니다. 실제 출입 인증 시에는 학습 완료 모델을 Raspberry Pi 5에 탑재하여 로컬에서 추론합니다.

공개 저장소에는 학습된 모델 가중치를 포함하지 않습니다. 대회 시연 장치의 Raspberry Pi에만 모델을 별도로 설치합니다.
