# 연속 압력 입력의 사용자 특징을 활용한 AI 기반 출입 인증 시스템

제24회 임베디드 SW 경진대회 자유공모 부문 출품작입니다. 인하대학교 NCLAB에서 개발했으며, 사용자가 입력하는 연속적인 압력의 크기·지속시간·변화 흐름을 특징으로 추출해 등록된 사용자 패턴과 비교하는 출입 인증 시스템입니다.

## 시스템 개요

이 프로젝트는 **Arduino 기반 인증 단말기**와 **Raspberry Pi 기반 관리자·인증 애플리케이션**으로 구성됩니다.

- 일반 사용자는 인증 단말기에서 User ID와 압력 패턴을 입력합니다.
- Arduino Uno R4 Minima는 키패드와 FSR402 압력센서 입력을 수집하고 OLED·LED·솔레노이드 잠금장치를 제어합니다.
- Raspberry Pi 5는 사용자 등록 정보와 센서 캘리브레이션을 관리하고, 입력 패턴을 전처리해 AI 임베딩을 추출한 뒤 등록 패턴과 코사인 유사도로 비교합니다.
- 인증에 성공하면 Raspberry Pi가 결과를 Arduino에 전달하고 잠금장치가 해제됩니다.

## 핵심 기술

연속 압력 패턴은 같은 사용자가 반복해도 최대 압력, 입력 시간과 변화 흐름이 조금씩 달라질 수 있습니다. 따라서 원시 압력값의 완전 일치가 아니라, Siamese Network로 학습한 임베딩 공간에서 등록 패턴과 인증 패턴의 특징 벡터 유사도를 비교합니다.

일반적인 분류 모델처럼 사용자 ID 자체를 분류하지 않고 패턴 간 차이를 학습하기 때문에, 학습 완료 후 새로운 사용자를 등록할 때 모델을 다시 학습할 필요가 없습니다.

## 사용자 인증 흐름

1. 인증 단말기를 활성화합니다.
2. 키패드로 User ID를 입력하고 `*` 키로 확정합니다.
3. 등록된 사용자인 경우 압력 패턴 입력 안내가 표시됩니다.
4. 압력센서에 본인의 연속 압력 패턴을 입력합니다.
5. `*` 키로 패턴 입력을 종료합니다.
6. Raspberry Pi가 전처리와 AI 추론을 수행하고 등록 임베딩과 유사도를 비교합니다.
7. 인증 성공 시 잠금장치가 해제됩니다. 실패 시 안내에 따라 다시 입력합니다.

일반 사용자는 Raspberry Pi 관리자 애플리케이션을 직접 조작하지 않습니다.

## 관리자 사용 흐름

관리자는 Raspberry Pi에서 관리자 애플리케이션을 실행합니다.

1. Arduino 인증 단말기와 시리얼 연결을 설정합니다.
2. 최초 설치 또는 센서 환경이 변경된 경우 센서 캘리브레이션을 수행합니다.
3. 사용자 ID와 이름을 입력해 사용자를 등록하고 두 번의 압력 패턴을 수집합니다.
4. 등록 사용자 조회, 재등록, 정보 수정과 삭제 기능을 사용할 수 있습니다.
5. 운영 중 입력된 패턴의 인증 결과는 Arduino 단말기로 전달됩니다.

자세한 Raspberry Pi 설치와 운영 방법은 [`raspberrypi/README.md`](raspberrypi/README.md)를 참고하세요.

## 하드웨어 구성

### 인증 단말기

- Arduino Uno R4 Minima: 전체 장치 제어
- FSR402: 연속 압력 패턴 수집
- TLV9002: 압력센서 신호 증폭
- 1.3인치 OLED: 상태 및 사용자 안내 표시
- 키패드 NT-207NN-WB: User ID와 명령 입력
- LED: 잠금 및 입력 상태 표시
- MOSFET / 다이오드: 솔레노이드 구동 및 보호
- Solenoid Lock: 인증 성공 시 잠금 해제

### 인증·관리 장치

- Raspberry Pi 5
- Python 3.12
- NumPy / Matplotlib / ONNX Runtime / pyserial

## AI 모델 공개 범위

본 공개 저장소에는 **학습된 AI 모델의 가중치와 모델 배포 파일을 포함하지 않습니다.** 대회 시연 환경에서는 학습 완료 모델을 Raspberry Pi에 별도로 탑재해 실행합니다.

공개 코드에는 센서 데이터 처리, 전처리, ONNX 추론 연결, 임베딩 비교, 사용자 등록·인증 로직이 포함됩니다. 모델 파일이 없으면 실제 AI 인증은 실행할 수 없습니다.

## 모델 성능 평가

개발 과정에서는 사용자 단위로 개발 세트, 캘리브레이션 세트와 독립 테스트 세트를 분리했습니다. 개발 세트에서 4-fold 교차검증으로 모델과 하이퍼파라미터를 선정하고, 별도 캘리브레이션 세트에서 EER을 기준으로 인증 임계값을 결정한 뒤 고정된 모델과 임계값을 독립 테스트 세트에 적용했습니다.

- 캘리브레이션 EER: **6.1310%**
- 인증 임계값: **약 0.7437**
- 독립 테스트 FAR: **4.1960%**
- 독립 테스트 FRR: **5.4668%**
