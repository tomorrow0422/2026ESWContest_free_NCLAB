# Arduino 압력 패턴 인증 단말기

Arduino Uno R4 Minima에서 실행되는 인증 단말기 펌웨어입니다. 일반 사용자의 User ID와 연속 압력 패턴을 입력받고 Raspberry Pi에 전달하며, 인증 결과에 따라 OLED·LED와 솔레노이드 잠금장치를 제어합니다.

## 주요 역할

- 키패드에서 User ID 입력
- FSR402 압력센서 신호를 200Hz 주기로 수집
- Raspberry Pi와 USB 시리얼 통신
- OLED를 통한 사용자 안내
- LED를 통한 입력·잠금 상태 표시
- 인증 성공 시 솔레노이드 잠금 해제

AI 추론과 사용자 등록 정보 관리는 Arduino에서 수행하지 않고 Raspberry Pi 관리자·인증 애플리케이션이 담당합니다.

## 사용 하드웨어

- Arduino Uno R4 Minima
- FSR402 압력센서
- TLV9002 기반 센서 신호 증폭 회로
- NT-207NN-WB 키패드
- 1.3인치 128×64 I²C OLED
- 빨간색·초록색 LED
- N-MOSFET
- 보호 다이오드
- Solenoid Lock
- 솔레노이드용 외부 전원

실제 핀 번호와 장치 설정값은 `config.h`에서 확인할 수 있습니다.

## 사용자 인증 방법

1. 대기 상태에서 아무 키나 눌러 단말기를 활성화합니다.
2. 숫자 키로 User ID를 입력합니다.
3. `*` 키를 눌러 ID 입력을 완료합니다.
4. 등록된 사용자이면 OLED의 안내에 따라 압력센서에 자신의 압력 패턴을 입력합니다.
5. `*` 키를 눌러 압력 입력을 종료합니다.
6. Raspberry Pi가 등록 패턴과 비교하는 동안 결과를 기다립니다.
7. 인증에 성공하면 초록 LED가 켜지고 잠금장치가 해제됩니다.
8. 인증에 실패하면 OLED 안내에 따라 다시 입력합니다.

## 키 동작

### User ID 입력 중

- 숫자 키: User ID 입력
- 짧은 `#`: 마지막 한 자리 삭제
- 긴 `#`: 전체 ID 삭제, 빈 상태에서는 대기 화면으로 복귀
- `*`: User ID 확정 및 등록 여부 확인

### 압력 패턴 입력 중

- `*`: 현재 패턴 입력 완료
- 짧은 `#`: 현재 압력 패턴을 처음부터 다시 입력
- 긴 `#`: 현재 등록·인증 작업 취소

### 인증 성공 상태

- `#`: 잠금장치를 즉시 다시 잠금

## 펌웨어 구조

`pressure_access_controller.ino`가 전체 상태 전환을 조정하고, 세부 기능은 역할별 파일로 분리되어 있습니다.

```text
pressure_access_controller/
├── pressure_access_controller.ino  # 전체 상태 머신과 장치 동작 연결
├── config.h                        # 핀 번호와 동작 설정
├── device_types.h                  # 공통 상태·명령 자료형
├── keypad_input.*                  # 키패드 스캔과 입력 처리
├── pressure_sampler.*              # 압력센서 샘플링
├── display_ui.*                    # OLED 화면 출력
├── serial_protocol.*               # Raspberry Pi 통신 메시지 처리
├── serial_line_reader.*            # 시리얼 라인 수신
└── *_policy.*                      # 상태별 입력·전환 정책
```

## Raspberry Pi 통신

Arduino와 Raspberry Pi는 USB 시리얼을 사용하며 기본 보드레이트는 `115200`입니다.

Arduino는 User ID 확인 요청, 압력 패턴 샘플과 장치 상태를 Raspberry Pi에 전달합니다. Raspberry Pi는 사용자 등록 여부, 패턴 수집 요청, 인증 성공·실패와 장치 제어에 필요한 상태를 Arduino에 전달합니다.

세부 메시지 형식은 [`../../docs/serial-protocol.md`](../../docs/serial-protocol.md)를 참고하세요.

## 압력 데이터 수집

FSR402 신호는 증폭 회로를 거쳐 Arduino의 아날로그 입력으로 들어옵니다. 펌웨어는 약 5ms 간격, 즉 200Hz로 압력값을 읽어 시간 순서대로 Raspberry Pi에 전달합니다.

인증에서는 단일 압력값이 아니라 입력 시작부터 종료까지의 압력 크기와 시간 변화 전체를 사용합니다.

## 안전한 잠금장치 제어

부팅 과정에서 출력 상태가 불안정해 문이 의도치 않게 열리는 것을 막기 위해, 펌웨어는 장치 초기화 단계에서 잠금 출력을 우선 설정합니다. 인증에 성공한 경우에만 MOSFET을 통해 솔레노이드를 구동합니다.

## 소스코드 주석 규칙

공개 제출본의 Arduino 소스는 다음 원칙으로 주석을 작성합니다.

- 상태나 함수 이름만 반복하지 않고 해당 코드가 필요한 이유를 설명합니다.
- 사용자 입력, 센서 수집, 통신, 잠금 제어처럼 시스템 동작에 직접 영향을 주는 부분을 중심으로 설명합니다.
- 짧은 설명은 `//`, 모듈이나 상태 흐름 설명은 `/* ... */` 형식을 사용합니다.
- 심사 시 코드 흐름을 바로 파악할 수 있도록 한국어 설명을 기본으로 사용합니다.
