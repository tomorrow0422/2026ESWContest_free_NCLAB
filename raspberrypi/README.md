# Raspberry Pi 관리자·인증 애플리케이션

Raspberry Pi 5에서 실행되는 관리자용 애플리케이션입니다. Arduino 인증 단말기와 시리얼로 통신하며 사용자 등록·관리, 센서 캘리브레이션, 압력 패턴 전처리, AI 임베딩 추론과 인증 판정을 담당합니다.

일반 사용자는 이 애플리케이션을 직접 조작하지 않습니다. 일반 사용자는 Arduino 기반 인증 단말기에서 User ID와 압력 패턴만 입력합니다.

## 실행 환경

- Raspberry Pi 5
- 64-bit Raspberry Pi OS
- Python 3.12.x
- Arduino Uno R4 Minima 기반 인증 단말기
- 대회 시연용 AI 모델 파일

## 설치

```bash
cd raspberrypi
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

설치 후 다음 명령으로 관리자 애플리케이션을 실행할 수 있습니다.

```bash
nclab-auth
```

또는 모듈 형태로 실행합니다.

```bash
python -m nclab_alt_auth.main
```

### Matplotlib 사용 이유

`matplotlib`은 디버그 그래프를 표시하기 위한 도구가 아니라 **실제 인증 전처리의 일부**입니다. Arduino에서 수집한 시간 순서의 FSR 압력 신호를 학습 데이터와 동일한 방식의 64×64 흑백 선 이미지로 래스터화할 때 사용합니다. 따라서 공개 실행 코드에서도 필수 의존성으로 유지합니다.

## AI 모델 준비

학습된 AI 모델 가중치는 공개 저장소에 포함하지 않습니다. 대회 시연용 Raspberry Pi에는 모델 파일과 설정 파일을 별도로 설치합니다.

기본 경로는 다음과 같습니다.

```text
/opt/nclab-alt-auth/model/signature_embedding_v1.onnx
/opt/nclab-alt-auth/model/model_config.json
```

다른 위치를 사용할 경우 다음 환경변수를 지정합니다.

```bash
export NCLAB_MODEL_PATH=/path/to/signature_embedding_v1.onnx
export NCLAB_MODEL_CONFIG_PATH=/path/to/model_config.json
```

모델 또는 설정 파일이 없으면 애플리케이션은 실제 AI 인증을 시작하지 않습니다.

## 최초 실행 순서

1. AI 모델 파일이 시연 Raspberry Pi에 설치되어 있는지 확인합니다.
2. Arduino 인증 단말기를 USB 시리얼로 연결합니다.
3. `nclab-auth`를 실행합니다.
4. `관리자 메뉴`에서 `시리얼 연결 설정`을 선택합니다.
5. 감지된 Arduino 포트를 선택합니다.
6. 보드레이트는 펌웨어 기본값인 `115200`을 선택합니다.
7. 최초 설치 또는 센서 환경 변경 후에는 센서 캘리브레이션을 수행합니다.
8. 사용자 등록을 진행합니다.

## 관리자 메뉴

관리자 메뉴에서는 다음 기능을 제공합니다.

- 시리얼 연결 설정
- 사용자 등록
- 등록 사용자 목록 조회
- 사용자 재등록
- 사용자 정보 수정
- 사용자 삭제
- 센서 캘리브레이션
- 압력센서 실시간 확인
- 시스템 상태 확인

## 사용자 등록

1. Arduino 연결과 센서 캘리브레이션을 완료합니다.
2. 관리자 메뉴에서 `사용자 등록`을 선택합니다.
3. User ID와 사용자 이름을 입력합니다.
4. Arduino 단말기의 안내에 따라 첫 번째 압력 패턴을 입력합니다.
5. 두 번째 압력 패턴을 같은 방식으로 입력합니다.
6. 두 입력의 임베딩 유사도가 등록 기준을 만족하면 평균 임베딩을 사용자 등록 정보로 저장합니다.

User ID는 Arduino 키패드와 시리얼 규약에 맞춰 ASCII 숫자 1~10자리만 사용합니다. 예를 들어 `0001`은 앞자리 0을 포함한 별도 ID로 저장됩니다.

## 사용자 인증

인증은 일반 사용자가 Arduino 단말기에서 시작합니다.

1. 사용자가 User ID를 입력합니다.
2. Raspberry Pi가 등록된 사용자인지 확인합니다.
3. 단말기에서 연속 압력 패턴을 수집합니다.
4. Raspberry Pi가 센서 캘리브레이션을 반영해 입력을 전처리합니다.
5. AI 모델로 64차원 임베딩 벡터를 추출합니다.
6. 등록된 임베딩과 코사인 유사도를 계산합니다.
7. 설정된 인증 임계값 이상이면 인증 성공, 미만이면 인증 실패로 판정합니다.
8. 결과를 Arduino에 전달해 잠금장치와 표시 장치를 제어합니다.

동일 사용자의 입력도 매번 압력 크기와 시간 흐름이 조금씩 달라질 수 있으므로 원시 압력값의 완전 일치가 아니라 학습된 임베딩 공간의 유사도를 기준으로 인증합니다.

## 센서 캘리브레이션

센서 캘리브레이션은 압력이 가해지지 않은 상태의 기준 신호를 측정해 장치별 센서 편차와 평상시 노이즈를 전처리에 반영하기 위한 과정입니다.

다음 경우 다시 수행하는 것을 권장합니다.

- 인증 장치를 처음 설치한 경우
- 압력센서 또는 증폭 회로를 교체한 경우
- 센서 고정 상태나 배선이 변경된 경우
- 평상시 센서값이 기존과 크게 달라진 경우

## 운영 데이터

사용자 등록 정보와 인증 상태는 다음 SQLite 파일에 저장됩니다.

```text
raspberrypi/data/enrollments.sqlite3
```

이 파일은 공개 저장소에 포함되지 않으며 `.gitignore`로 제외됩니다. 시연 장치 교체나 초기화 전에는 필요한 경우 별도 위치에 백업합니다.

## Arduino 연결 문제 확인

연결되지 않는 경우 다음을 확인합니다.

1. Arduino가 Raspberry Pi에 USB로 연결되어 있는지 확인합니다.
2. 관리자 메뉴의 포트 목록에서 Arduino 장치가 표시되는지 확인합니다.
3. 보드레이트가 펌웨어와 동일한 `115200`인지 확인합니다.
4. 다른 프로그램이 같은 시리얼 포트를 사용 중인지 확인합니다.
5. 연결을 다시 설정한 뒤 시스템 상태를 확인합니다.

통신 메시지와 상태 전이는 [`../docs/serial-protocol.md`](../docs/serial-protocol.md)를 참고하세요.
